# zero2tech：从零到全栈

这是一个用于记录“从零到全栈”开发学习过程的项目仓库。之后可以在这里编写、整理和迭代前端、后端、数据库、工程化等相关练习代码。

## 当前内容

项目目前包含一个最基础的网页示例：

- `index.html`：网页结构
- `styles.css`：页面样式
- `script.js`：页面交互逻辑

这个示例展示了一个居中的卡片。点击按钮后，页面文字会发生变化，并且卡片会出现一个简单的点击反馈效果。

## 如何运行

直接用浏览器打开 `index.html` 即可：

```text
index.html
```

也可以在 VS Code 中使用 Live Server 插件打开，方便后续开发时自动刷新页面。

## 学习目标

后续可以逐步添加：

1. HTML 基础结构练习
2. CSS 布局与响应式设计
3. JavaScript DOM 操作与事件处理
4. 前端项目工程化
5. 后端接口与数据库练习
6. 全栈项目整合

## 项目原则

- 每次学习都留下可运行的代码
- 每个功能尽量拆分清楚文件职责
- 保持提交记录清晰，方便复盘学习路径
